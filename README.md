# AgentPay — The Stripe for Autonomous AI Agents

## Why AgentPay?
Autonomous agents struggle to accept payments directly. They need a simple, agent-native API to trigger checkouts, verify subscriptions, and bill clients without human intervention.

## Features
- Agent-native Payment API
- Subscription Management for Agents
- Verification Webhooks
- Multi-currency Support

## Quick Start
```bash
npm i -g agentpay-cli
agentpay checkout --amount 99 --description "AI Agent License"
```
